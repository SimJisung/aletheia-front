# Plan: 관련 주제 다중 선택 기능

## 1. 개요

### 1.1 기능 요약
ThoughtFragment 작성 시 관련 주제(topicHint)를 **여러 개** 선택/추가할 수 있도록 개선

### 1.2 현재 문제
- `TopicSelector`가 단일 값(`string | null`)만 지원
- 프리셋 주제와 커스텀 주제 중 하나만 선택 가능
- 사용자가 여러 관련 주제를 연결하고 싶어도 불가능

### 1.3 목표
- 프리셋 주제 복수 선택 지원
- 커스텀 주제 여러 개 추가 지원
- 선택된 주제들을 chip 형태로 표시 및 개별 삭제 가능

## 2. 영향 범위

### 2.1 변경 대상 파일
| 파일 | 변경 내용 |
|------|-----------|
| `src/components/fragments/TopicSelector.tsx` | 다중 선택 로직으로 전환 |
| `src/components/fragments/CustomTopicModal.tsx` | 기존 선택에 추가하는 방식으로 변경 |
| `src/types/fragment.ts` | 타입 확장 (선택적) |

### 2.2 API 영향
- 현재 백엔드 `topicHint`는 `string?` 타입
- 프론트에서 다중 선택 시 쉼표 구분 문자열로 전송 (예: `"work,health,미래"`)
- 또는 배열을 JSON 문자열로 전송

### 2.3 영향받는 컴포넌트
- Fragment 생성 폼 (onboarding, fragments 페이지)
- Fragment 상세 보기 (주제 표시)

## 4. 제약 조건

### 4.1 기술적 제약
- 백엔드 `topicHint` 필드가 단일 문자열이므로, 프론트에서 직렬화 필요
- 기존 데이터와의 호환성 유지 (단일 값도 정상 표시)

### 4.2 비즈니스 제약
- PROS 철학: 주제는 사용자의 과거 패턴 분류 용도로만 사용
